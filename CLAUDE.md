# Rules

1. Do exactly what is asked. Nothing more, nothing less.
2. Before adding anything beyond the request (features, refactors, new files, dependencies), propose it first and wait for approval. Do not act on your own.
3. No code comments, ever.
4. Only write tests directly tied to the requested task. No extra tests.
5. Do not create unnecessary files or write unnecessary code.
6. Only read files strictly needed for the current task/route. Avoid reading extra files as much as possible.
7. Never touch code unrelated to the current task, even in passing.
8. If you notice a functional, design, or other anomaly, report it — do not fix it yourself unless asked.
9. Never run git commands (commit, push, branch, etc.) without explicit approval.
10. Never install a new dependency without asking first.
11. If a request is ambiguous, ask — do not guess.
12. At the end of a task, give a short summary only (changed files). No long explanations.
13. Never modify sensitive configuration files without explicit approval.
14. Avoid unnecessary thinking, extra checks, extra reading, extra exploration, and long responses. Be direct and minimal.
